# 🚗 Fuel Route Optimization API (Spotter AI Backend Assignment)

## 📌 Overview
This project is a **Django REST API** that calculates the most **cost-effective fuel stops** along a driving route within the **United States**.

The API:
- Accepts **start and end locations** within the USA
- Computes a driving route using a **free routing API**
- Determines **optimal fuel stops** based on fuel prices
- Respects a **maximum vehicle range of 500 miles**
- Calculates **total fuel cost** assuming **10 miles per gallon**

---

## 🛠 Tech Stack
- **Backend:** Django (latest stable)
- **API Framework:** Django REST Framework
- **Routing API:** OpenRouteService (free tier)
- **Data Source:** CSV fuel price dataset
- **Environment Variables:** python-dotenv
- **Testing Tool:** Postman
